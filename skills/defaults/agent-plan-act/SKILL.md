# Plan / act

1. Restate the goal in one sentence.
2. List required capabilities.
3. Plan ≤5 steps.
4. Act only under granted caps. On this standalone tip: local corpus search
   works offline; mail, host files, live portals, and intent.resolve stay
   Offline stubs — do not invent hits.
5. Report outcomes; arm Doc rows the user can open from the baked index.
6. Remaining risks: missing grants stay `Need` — never invent hits.

## Home field

Natural language on Home (`i wanna work on my paper`) is not bare keyword
search. The guest builds a short local plan from the goal text (keywords +
fixed checklist), searches the baked corpus under grants, and opens a Brief
with Doc rows. There is **no** Live host `intent.resolve` on this tip. The ISO
never runs a model.
