teddy OS

A desktop operating system built around one idea: the machine should do what you ask, and nothing you did not grant. It runs from a USB stick or a virtual machine without touching what is already on your computer. The first thing it does is ask what it is allowed to use — your files, the network — and every answer is off until you turn it on, and changeable afterwards.

Pick the image that matches your machine.

What you get

  • A desktop that starts without an account, a password, or a login screen.
  • A setup journey on first boot, in plain language, where you choose what it may touch.
  • Search in the dock. Its built-in answers work with no network; searching the web is a separate switch you turn on yourself.
  • An Install option if you decide to keep it — until you pick that, nothing is written to your disk.

Trying it safely

  • Easiest: run the image in a virtual machine — nothing on your computer is touched.
  • Apple Silicon Mac: use UTM with the ARM64 image. VirtualBox's Apple Silicon build is a developer preview and will boot this image to a blank screen — that is a limitation of VirtualBox, not of the image, and there is nothing you can set to work around it.
  • Intel Mac, PC or Linux: any virtual machine, or write the x86-64 image to a USB stick and boot real hardware.
  • Give the machine 4 GB of memory or more. It is a full desktop.

Writing it to a USB stick

  1. Find the disk: diskutil list (macOS) or lsblk (Linux).
  2. Write it, replacing diskN with your stick — this erases that disk:
    sudo dd if=teddyos-amd64.iso of=/dev/rdiskN bs=4m
  3. Boot from it. On a Mac, hold Option at the chime; on a PC, the one-time boot menu key.

The research kernel

There is a second, much smaller thing with the same name: a Rust kernel that boots in a couple of seconds straight to a search field, with no desktop and no login. It is a research build rather than something to use day to day, and it is where the ideas here get tried first.
x86-64 kernel image · ARM64 kernel image

Free and unfinished — it is a personal project, not a product, and it will have rough edges. It never phones home: there is no telemetry, and the only network access is a connector you switch on.
